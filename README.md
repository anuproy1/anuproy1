# Anup Roy — VLSI portfolio

A responsive, self-contained portfolio for GitHub Pages. No installation or build required.

## Preview
Double-click index.html to open it in a browser.

## Personalize before publishing
1. Open index.html in a text editor and find `const profile` near the bottom.
2. Fill in your real GitHub, LinkedIn, email, resume, ALU repository, and thesis links. Keep unknown fields empty. For a resume stored beside index.html, use `resume: 'resume.pdf'` and include the PDF in the repository.
3. Review every education, project, and skill statement for accuracy. This draft uses information shared in conversation, not an independent review of your project files. Remove anything you cannot explain in an interview.
4. Add ALU source code, testbench, constraints, representative reports, and a layout image to the linked project repository. Include the clock/IO constraints and timing corner with each reported timing result. Do not publish confidential or restricted files.

## Publish with GitHub Pages
1. Create a public GitHub repository named YOUR-USERNAME.github.io, replacing YOUR-USERNAME with your actual username.
2. Upload the extracted files to the repository root, so index.html is directly in the root (not inside a portfolio folder). Commit them to main.
3. Open Settings > Pages. Under Build and deployment, select Deploy from a branch, main, and / (root), then Save.
4. Wait for the deployment to finish. The site address is https://YOUR-USERNAME.github.io/.

Official instructions: https://docs.github.com/en/pages/quickstart

This package is a draft; it has not been published to GitHub. Link behavior and layout should be checked in your browser before publishing.

Duplicate the previous-experience article for additional positions. Do not leave instructional placeholders on the live site.
